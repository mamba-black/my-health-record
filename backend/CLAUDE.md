# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

> **La documentación del proyecto vive en [AGENTS.md](./AGENTS.md) y en los `AGENTS.md` de cada crate.**
>
> En [AGENTS.md](./AGENTS.md) están las **reglas transversales**: la Arquitectura Cebolla y
> sus capas, la inyección de dependencias, las convenciones de código, los comandos de
> build/test, la guía de testing, las reglas de commits/PR y la configuración de entorno e
> infraestructura local.
>
> En `crates/<dominio>/AGENTS.md` están las **reglas funcionales de ese contexto acotado**
> (sección «Reglas de Dominio»), junto a su modelo FHIR. El mapa completo de contextos está
> en [AGENTS.md](./AGENTS.md) §2.
>
> Consulta y mantén ambos niveles como única fuente de verdad: una regla transversal no se
> duplica en un crate, y una regla de dominio no se escribe en la raíz.
